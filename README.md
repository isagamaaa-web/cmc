## 🌟 Overview

**Central Medium Clinic (CMC)** provides 24/7 medical services, specialist consultations, and diagnostic reporting. This platform offers a seamless digital interface for patients to explore medical specialties, schedule clinic appointments, and interact with an AI-driven support assistant.

**Live Application:** [https://cmc-medical.vercel.app](https://cmc-medical.vercel.app)

---

## ✨ Features

- **🩺 Medical Specialties Showcase:** Clear catalog highlighting services such as Internal Medicine, Emergency Care, Diagnostics, and Patient Consultations.
- **📅 Interactive Booking Engine:** Simple flow allowing patients to book clinic visits online.
- **🤖 Embedded AI Medical Assistant:** Floating chatbot widget powered by specialized APIs for real-time patient assistance.
- **🎨 Glassmorphic Medical UI:** Modern, fully responsive design built with custom UI components and Tailwind CSS.
- **🌍 Multi-Language Ready:** Framework in place for regional localization (English / Amharic support).

---

## 🛠️ Tech Stack

- **Frontend:** [TanStack Start](https://tanstack.com/start), [React 18](https://react.dev/), [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Realtime, Edge Functions)
- **Deployment:** [Vercel](https://vercel.com/) Edge Network
